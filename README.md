# dev-portfolio

Portfolio and visual design system of **Deva (Devasenathipathi M)** — Graphic designer specializing in brand identity, bilingual Tamil–English typography, poster layout, and visual marketing systems.

## 🎨 Visual Identity & System
- **Core Style:** Playful neo-retro editorial design with handcrafted marker highlights and collage aesthetics.
- **Palette:** `#E0E0E0` (Canvas), `#FFB914` (Highlight Yellow), `#333333` (Charcoal), `#17118B` (Deep Navy).
- **Typography:** Lilita One & Fredoka (Display & Headings), Plus Jakarta Sans (Body).

## 🚀 Projects Featured
1. **Kaapi Kadai** — Traditional South Indian filter coffee kiosk brand identity with bilingual packaging and matchbox labels.
2. **Margazhi Season** — Screenprint music festival poster series celebrating South Indian classical instruments.

## 🛠️ Tech Stack
- Semantic HTML5
- Custom CSS3 Design System (Vanilla CSS with dynamic clamp typography and calm motion tokens)
- Vanilla JavaScript for interactive reference switcher, project modals, and calm motion system
